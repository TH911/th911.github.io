# 题目描述

## 题目描述

JOI 美术馆计划近期举办一场绘画展览。馆方拥有编号为 $1$ 至 $N$ 的 $N$ 幅画作，其中画作 $i$（$1 \le i \le N$）的**美观值**为 $A_i$。在展览中这些画作将排成一行展示，但具体排列顺序尚未确定。

共有 $M$ 家杂志将对展览进行报道。这些杂志按影响力从大到小依次编号为 $1$ 至 $M$。每家杂志将发布展览中某一连续段画作的摄影照片。具体来说，杂志 $j$（$1 \le j \le M$）将发布排列中从左数第 $L_j, L_j + 1, \ldots, R_j$ 幅画作的照片。杂志 $j$（$1 \le j \le M$）报道的**吸引力**定义为该杂志所覆盖画作的**美观值之和**。

JOI 君作为 JOI 美术馆的馆长，希望通过排列画作使得这些杂志的报道更具吸引力，从而吸引更多参观者。由于影响力更大的杂志能触达更多受众，他优先希望提升更具影响力杂志的报道吸引力。

具体而言，设 $b_j$ 为杂志 $j$（$1 \le j \le M$）报道的吸引力，则 JOI 君希望排列画作，使得序列 $b = (b_1, b_2, \ldots, b_M)$ 的字典序最大化。

> 在这里，对于不同的数列 $b = (b_1, b_2, \ldots, b_M)$ 和 $b' = (b'_1, b'_2, \ldots, b'_M)$，所谓“$b$ 在字典序上大于 $b'$”，是指存在满足 $b_k \neq b'_k$ 的最小下标 $k$（$1\leq k\leq M$），且对于该 $k$ 有 $b_k>b'_k$。

请编写一个程序，根据待展览画作的信息和报道展览的杂志信息，计算当画作排列使序列 $b=(b_1,b_2,\cdots,b_M)$ 字典序最大化时，每家杂志报道的吸引力。

## 输入格式

第一行包含两个整数 $N$ 和 $M$。

第二行包含 $N$ 个整数 $A_1, A_2, \ldots, A_N$。

接下来 $M$ 行，每行两个整数 $L_i, R_i$，表示第 $i$ 家杂志报道的区间。

## 输出格式

输出 $M$ 行，第 $i$ 行的正整数为 $b_i$。

# 官方题解

## 测试点 1~2

我会暴力！

直接枚举分配方式，暴力计算即可，时间复杂度 $\mathcal O(n!\times\text{poly}(n))$

## 测试点 3~4

我会更好的暴力！

~~也许可以~~状压或者使用其它多项式时间复杂度的算法。

## 测试点 5~8

我会 $\mathcal O(n^2)$ 暴力！

观察整个过程，其实就是给每个数一个 $0/1$ 序列，要求排序并计算最后分配方案的权值，使用基数排序即可。

## 测试点 9~10

我会 $\mathcal O\left(\dfrac{n^2}{k}\right)$ 暴力！

把上述的基数排序压位处理，这样就能让复杂度除以一个常数。

## 测试点 11~12

我会 $\mathcal O(n\times \text{poly}(\log n))$ 暴力！

给一个 $\mathcal O(n\log^3 n)$ 的做法。

考虑普通排序的过程，这里实际上只要实现快速比较即可。

对每个 $0/1$ 序列开一个权值线段树，使用可持久化的结构建好即可，然后二分找到第一个不同的位，可以用线段树上维护哈希值实现。

## 测试点 13~15

我会 $\mathcal O(n\log^2 n)$ 做法！

依旧考虑怎么比较两个序列，发现只有找到第一个只修改两者中的一个的操作，将限制写成偏序形式做到 $\mathcal O(n\log^3 n)$。

考虑换维扫描线，扫每一位，维护比较的过程即可做到 $\mathcal O(n\log^2 n)$。

## 测试点 16~20

我会 $\mathcal O(n\log n)$ 正解！

考虑依旧维护可持久化的过程，使用类似 [NOI 2025] 数字树的 trick，我们把值域开到 $2^k$，然后从下层往上层排序。

叶子节点是简单的，往上的层中的每个位置都有两个值做双关键字排序。

可以发现过程类似后缀排序，使用基数排序便可做到 $\mathcal O(n\log n)$ 的复杂度。

## another solution

我会空间 $\mathcal O(n)$ 正解！

注意到空间带老哥实在不太优秀，能不能消灭老哥呢？

发现每次操作会把中间操作的部分和两边分开成两个独立的问题，并且两边是偏序关系。

考虑使用平衡树维护，每次找到要修改的区间，分裂成两颗平衡树即可。

发现总分裂次数是 $\mathcal O(n)$ 级别的，总时间复杂度 $\mathcal O(n\log n)$，空间复杂度 $\mathcal O(n)$。

关于实现细节：考虑如何找到需要分裂的平衡树。

发现如果平衡树对应的区间有交但没有完全包含修改区间的话，直接分裂即可。

否则，包含整个修改区间的平衡树对应的区间间必为包含关系，因为我们是一个个分裂出这个结构的。到外层某颗树不需要修改的话那更外层的其它树也不需要修改，直接按右端点从小到大的顺序一一判断是否需要修改即可。

继续优化，发现瓶颈在于存储每个点所处的区间编号。

因此考虑优化，记录每个点是否处于某个区间中，使用可持久化权值线段树配合扫描线即可高效维护。

然而我们需要对于 $i,j$ 判断 $i,j$ 谁更优先，也就是求从小到大第一个不同的位置。考虑线段树用哈希判左子树相同，线段树二分即可。

哈希就给每个 $i$ 配一个随机数 $w_i$，加入/删除 $i$ 就在线段树上对应位置异或 $w_i$。子树和就是异或和。

		int mid=t[p].l+t[p].r>>1;
		if(!t[p].lChild){

				t[p].rChild=create({mid+1,t[p].r});
			}
			t[p].rChild=add(t[p].rChild,x,k);
		}

	}

	int query(int x,int y){
		int p=root[x],q=root[y];
		if(t[p].value==t[q].value){
			return 0;

		if(t[tag[1][x]].value!=t[tag[1][y]].value){
			p=tag[1][x],q=tag[1][y];
		}else if(t[tag[0][x]].value!=t[tag[0][y]].value){
			p=tag[0][x],q=tag[0][y];
		}
		while(t[p].l!=t[p].r){
			//~ down(p);
			if(t[t[p].lChild].value==t[t[q].lChild].value){
				p=t[p].rChild,q=t[q].rChild;
			}else{
				p=t[p].lChild,q=t[q].lChild;
			}
		}
		return t[p].l;
	}

		root[i]=root[v];

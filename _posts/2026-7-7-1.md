# 题目描述

## 题目背景

YYX 转职成了园艺师！

## 题目描述

YYX 的后院有一排总共 $L$ 个灌木，从左到右依次编号为 $0,1,\dots, L-1$。它们的初始高度都为 $X$ 米，每过一天，$\forall 0\le i < L$，第 $i$ 棵灌木将生长 $i$ 米。

YYX 并不希望灌木太高，她有一把魔法剪刀，长度为 $m$ 米，当她对一棵灌木进行修剪时，这棵灌木将**恰好**减少 $m$ 米。当然，YYX 不希望把任何灌木连根拔起，因此她只会对那些高度 $\ge m$ 米的灌木进行修剪，并会尽可能地进行修剪直到不存在一个灌木高度超过 $m$ 米。

过了 $Y$ 天后，YYX 心血来潮，希望知道她家此时中最高的灌木和最低的灌木的高度。但是她太笨了，所以她找到了你，希望你帮她解决问题。

## 输入格式

输入文件：`garden.in`。

本题采用多组测试。

第一行一个整数 $T$ 表示数据组数。

对于每组数据，一行四个整数 $L, X, Y, m$ 分别表示灌木个数，灌木初始高度，经过的天数，剪刀的长度。

## 输出格式

对于每组数据分别输出一行两个整数，分别表示最高灌木的高度和最低灌木的高度。

# 官方题解

给定 $X, Y, m, L$，求：

$$f_{\max} = \max_{0 \le i < L}\{(X + iY) \bmod m\}$$

$$f_{\min} = \min_{0 \le i < L}\{(X + iY) \bmod m\}$$

多组测试，$1 \le T \le 10^5$，$1 \le L, X, Y, m \le 10^9$。

令 $f(x,y,m,l) = \max\limits_{0 \le i < l}\{(x + iy) \bmod m\}$，则最小值可以表示为：

$$m - 1 - f(m - 1 - x,\ m - y,\ m,\ l)$$

因此只需快速求出 $f$。

## Subtask 1

直接枚举 $i$ 分别求，单次复杂度 $O(L)$，总复杂度 $O(\sum L)$。

## Subtask 2

设置阈值 $B$，将 $[0, l)$ 按 $B$ 个一段进行分段，即分解 $i = jB + k$，其中 $0 \le k < B$，最后一段长度不足 $B$ 的暴力处理。

枚举 $j$ 时，令 $x' = (x + jBy) \bmod m$。预处理 $s_k = ky \bmod m$，如果 $s_k > m - 1 - x'$，则 $(x + (jB + k)y) \bmod m = x' + s_k - m < x'$ 一定不优。因此只需找到满足 $s_k \le m - 1 - x'$ 的最大 $s_k$ 即可。对 $s_k$ 排序后二分查找。

$j$ 的数量为 $O(l / B)$，总复杂度 $O(\sum (L/B + B)\log B)$，取 $B = \sqrt{L}$ 即可。

## Subtask 3

不妨 $0 \le x, y < m$。若 $y = 0$ 或 $x + (l - 1)y < m$，直接返回答案。

否则答案一定落在 $[m - y, m)$ 中。从大到小枚举 $r$，尝试找到最小的 $i$ 使得：

$$iy \equiv r - x \pmod m$$

令 $y, r - x, m$ 同时除以 $\gcd(y, m)$ 后求逆元即可。

单次复杂度 $O(y \log m)$，总复杂度 $O(\sum Y \log m)$。

## Subtask 4

不妨 $0 \le x, y < m$。若 $y = 0$ 或 $x + (l - 1)y < m$，直接返回答案。

否则将 $[0, m)$ 拆成若干段：

$$[m-y,m),\ [m-2y,m-y),\ \dots,\ [m-ky,m-(k-1)y),\ [0, m-ky)$$

其中 $k = \lfloor m / y \rfloor$。只需关心落在 $[m-y, m)$ 的那些 $(x + iy) \bmod m$。

设第一次落在 $[m-y, m)$ 的值为 $a_0 = (x + ty) \bmod m$，其中：

$$t = \left\lfloor \frac{m - 1 - x}{y} \right\rfloor$$

后续落在 $[m-y, m)$ 的值为：

$$a_k = m - y + \big(a_0 - (m - y) - km\big) \bmod y$$

落在 $[m-y, m)$ 的个数为 $\left\lfloor \dfrac{x + ly}{m} \right\rfloor$。

因此有：

$$f(x,y,m,l) = m - y + f\left(a_0 - (m - y),\ -m,\ y,\ \left\lfloor \frac{x + ly}{m} \right\rfloor\right)$$

这相当于将 $(y, m)$ 规模的问题转化为 $(-m \bmod y, y)$ 规模的问题。但直接这样写复杂度不对。

利用对称性：

$$f(x,y,m,l) = f(x + (l-1)y,\ -y,\ m,\ l)$$

将后者反转，即可转化为 $(m \bmod y, y)$ 规模的问题。

单次复杂度 $O(\log m)$，总复杂度 $O(\sum \log m)$。

```cpp
#include <bits/stdc++.h>
typedef long long ll;
using namespace std;

// i in [0,l), \max\{x + (i-1)y\}
int qmax (int x, int y, int m, ll l) {
  if (y == 0) return x;
  int t = (m - 1 - x) / y;
  if (t >= l - 1) return x + (l - 1) * y;
  ll len = (x + y * l) / m;
  return m - y + qmax(((x + y * t - (m - y) - 1ll * (len - 1) * m) % y + y) % y, m % y, y, len);
}

// i in [0,l), \min\{x + (i-1)y\}
int qmin (int x, int y, int m, ll l) {
  return m - 1 - qmax ((m - 1 - x) % m, (m - y) % m, m, l);
}

int l, x, y, m;

void sol () {
  scanf ("%d%d%d%d", &l, &x, &y, &m);
  x = x % m;
  y = y % m;
  printf ("%d %d\n", qmax (x, y, m, l), qmin (x, y, m, l));
}

int main () {
  int T;
  scanf ("%d", &T);
  while (T--) sol ();
  return 0;
}
```

# 个人题解

设：

$$
f(x,y,m,n)=\max_{i=0}^{n-1}((x+yi)\bmod m)\\
g(x,y,m,n)=\min_{i=0}^{n-1}((x+yi)\bmod m)
$$

可以发现，$x+yi\bmod m$ 的图象是一段一段的。但是我们需要的只是整点的取值。

不妨先考虑 $g(x,y,m,n)$ 的求法。

最大值肯定是在 $x+yi$ 大于等于 $km$ 且尽可能小的地方（谷底），可列：

$$
\begin{aligned}
x+yi&\geq km\\
i&\geq\dfrac{km-x}y
\end{aligned}
$$

当 $i=\left\lceil\dfrac{km-x}y\right\rceil$ 时取到最小值，有：

$$
\begin{aligned}
\left(x+y\left\lceil\dfrac{km-x}y\right\rceil\right)\bmod m&=x+y\left\lceil\dfrac{km-x}y\right\rceil-km\\
&=x+(km-x+(y+km-x)\bmod y)\\
&=(km-x)\bmod y
\end{aligned}
$$

因此有：

$$
\min_{i=0}^{n-1}((x+yi)\bmod m)=\min_{i=0}^{K}((km-x)\bmod y)
$$

其中 $K=\left\lfloor\dfrac{x+y(n-1)}{m}\right\rfloor$。

可以发现这样就把问题的规模变小了，于是得到了 $\mathcal O(T\log m)$ 的做法。

而 $f$，考虑：

$$
f(x,y,m,n)=m-1-\min((m-1-x-yi)\bmod m)
$$

因而可以用 $g$ 求解。

# 题目描述

## 题目背景

YYX 转职成了游戏设计师！

## 题目描述

YYX 正在设计一款游戏。当游戏开始时，游戏界面会出现一排宝石，宝石共 $n$ 个，有三种种类：红宝石、蓝宝石、绿宝石。

玩家可以进行如下操作：

- 选择一个蓝宝石。然后分别选择一个红宝石和一个绿宝石，要求他们必须在蓝宝石的两侧，即，不能同时在蓝宝石左边或者同时在蓝宝石右边。
- 把这三个宝石一起拿走，并获得一分。

玩家可以一直操作直到不能操作，目标是得到最高的分数。

有一句话说得好：“策划一定要玩自己的游戏。”于是 YYX 决定对若干个初始游戏情况求解最高分数。

YYX 发现这太简单了，于是她决定加点难度，要求支持如下修改和查询：

- 把某个宝石的种类进行修改。
- 选择 $1 \le l \le r \le n$，询问假如只把第 $l$ 到第 $r$ 个宝石作为初始游戏情况，可能得到的最高分是多少。

但是她太笨了，所以她找到了你，希望你帮她解决问题。

## 输入格式

第一行两个正整数 $n, q$，分别表示宝石总数和修改/询问总数。

第二行一个长度为 $n$ 的只由 `r`, `b`, `g` 构成的字符串。第 $i$ 个字符是 `r` 代表第 $i$ 个宝石是红宝石，`b` 代表是蓝宝石，`g` 代表是绿宝石。

接下来 $q$ 行，每行形如：

- `1 x c`，其中 $1 \le x \le n$，$c \in \{\texttt{r}, \texttt{b}, \texttt{g}\}$，表示把第 $x$ 个宝石的种类修改为 $c$。
- `2 l r`，其中 $1 \le l \le r \le n$，表示询问假如只把第 $l$ 到第 $r$ 个宝石作为初始游戏情况，可能得到的最高分是多少。

## 输出格式

对于每个询问，回答一行一个整数表示答案。

# 官方题解

给定长度为 $n$ 的由 `r`, `b`, `g` 构成的字符串，每次单点修改或者对一个区间进行询问。询问形如把区间里的字符单独拿出，每次可以选择一个子序列 `rbg` 或者 `gbr` 删去，问最大删除数（即最多能形成多少个这样的三元组）。

$1 \le n, q \le 2 \times 10^5$。

## Subtask 1

可能删除的子序列只形如 `rbg`，同时由于种类顺序固定，只需要知道 $[l, r]$ 中三种宝石分别的数量即可，三者最小值即为询问答案。

可以用树状数组等实现，复杂度 $O(n + q \log n)$。

## Subtask 2

不妨 $l = 1, r = n$，考虑如何做。

假如子序列 `rbg` 的删除数为 $P$，子序列 `gbr` 的删除数为 $Q$。可以发现，前 $P$ 个 `r` 一定分别属于某个 `rbg`，后 $Q$ 个 `r` 一定分别属于某个 `gbr`。对于 `g` 也同理。

更多的，第 $i$ 个 `r`（$1 \le i \le P$）一定对应从右往左数第 $P - i + 1$ 个 `g`。第 $i$ 个 `g`（$1 \le i \le Q$）一定对应从右往左数第 $Q - i + 1$ 个 `r`。

那么假如我们枚举了 $P, Q$，问题就转化为这对 $P, Q$ 是否合法。此时相当于有若干条线段和若干个 `b`，一个 `b` 和线段匹配当且仅当 `b` 被线段覆盖，问能否给每条线段都能匹配。

这是经典问题，我们从左往右扫，遇到线段的左端点就把线段右端点加入堆中；遇到 `b` 就把堆中最小的右端点弹出。如果在遇到右端点之前没有弹出它则不合法，如果全程没有不合法则合法。

当 $P$ 越大，对应可以合法的最大的 $Q$ 越小，那么使用双指针，需要判定的次数为 $O(n)$，每次判定复杂度 $O(n \log n)$，总复杂度 $O(q n^2 \log n)$。

## Subtask 3

继续考虑匹配，由 Hall 定理，一对 $P, Q$ 合法的条件当且仅当，对于每个 $[p, q] \subseteq [1, n]$，被 $[p, q]$ 完全包含的线段数要小于等于 $[p, q]$ 中 `b` 的数量。

考虑刻画这个条件，记 $cntr_i, cntb_i, cntg_i$ 为前缀中 `r`, `b`, `g` 的数量。那么后者即为 $cntb_q - cntb_{p-1}$。

假如 $[p, q]$ 左边有 $R$ 个 `r`，右边有 $G$ 个 `g`，那么子序列 `rbg` 对应的线段中，最前 $R$ 个的左端点就是左边这些 `r`，最后 $G$ 个的右端点就是右边这些 `g`，所以被完全包含的线段数为 $\max(P - R - G, 0)$。对于子序列 `gbr` 对应的线段也同理。

那么就是要满足：

$$
\max(P - cntr_{p-1} - cntg_n + cntg_q, 0) + \max(Q - cntr_n + cntr_q - cntg_{p-1}, 0) \le cntb_q - cntb_{p-1}
$$

等价于 $\forall 1 \le p \le q \le n$：

- $P - cntr_{p-1} - cntg_n + cntg_q + Q - cntr_n + cntr_q - cntg_{p-1} \le cntb_q - cntb_{p-1}$
- $P - cntr_{p-1} - cntg_n + cntg_q \le cntb_q - cntb_{p-1}$
- $Q - cntr_n + cntr_q - cntg_{p-1} \le cntb_q - cntb_{p-1}$

那么可以分别求出 $P + Q, P, Q$ 的上界，从而得到 $P + Q$ 的最大值，仔细实现可以达到 $O(qn)$。

## Subtask 4

以第一个条件为例，移项后变为，$\forall l \le p \le q \le r$：

$$
P + Q \le cntr_r - cntr_{l-1} + cntg_r - cntg_{l-1} + (cntb_q - cntg_q - cntr_q) - (cntb_{p-1} - cntr_{p-1} - cntg_{p-1})
$$

令 $c_i = cntb_i - cntg_i - cntr_i$，那么单点修改相当于对 $c_i$ 后缀加减。要求 $\min_{l-1 \le i < j \le r}\{c_j - c_i\}$。这个可以线段树维护。

其他条件类似，复杂度 $O(n + q \log n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
static const ll INF = (ll)4e18;

struct Fenwick {
    int n;
    vector<int> bit;
    Fenwick(int n=0): n(n), bit(n+1,0) {}
    void add(int i,int v){ for(; i<=n; i+=i&-i) bit[i]+=v; }
    int sumPrefix(int i) const { int r=0; for(; i>0; i-=i&-i) r+=bit[i]; return r; }
    int rangeSum(int l,int r) const { return sumPrefix(r)-sumPrefix(l-1); }
};

/******** Tree for C: bestC = min_{i<j}(C[j]-C[i]) ********/
struct SegC {
    struct Node { ll mn, mx, best, lazy; };
    int n; // indices 0..n
    vector<Node> st;
    SegC() : n(0) {}
    SegC(const vector<ll>& arr){ init(arr); }

    void init(const vector<ll>& arr){
        n = (int)arr.size()-1;
        st.assign(4*(n+1), {0,0,INF,0});
        build(1,0,n,arr);
    }

    static Node mergeNode(const Node& L, const Node& R){
        Node res;
        res.mn = min(L.mn, R.mn);
        res.mx = max(L.mx, R.mx);
        res.best = min({L.best, R.best, R.mn - L.mx});
        res.lazy = 0;
        return res;
    }

    void apply(int p, ll d){
        st[p].mn += d;
        st[p].mx += d;
        st[p].lazy += d;
        // best unchanged (differences invariant)
    }
    void push(int p){
        ll d = st[p].lazy;
        if(d!=0){
            apply(p<<1,d);
            apply(p<<1|1,d);
            st[p].lazy=0;
        }
    }
    void pull(int p){
        st[p] = mergeNode(st[p<<1], st[p<<1|1]);
    }

    void build(int p,int l,int r,const vector<ll>& arr){
        st[p].lazy=0;
        if(l==r){
            st[p].mn = st[p].mx = arr[l];
            st[p].best = INF;
            return;
        }
        int m=(l+r)>>1;
        build(p<<1,l,m,arr);
        build(p<<1|1,m+1,r,arr);
        pull(p);
    }

    void rangeAdd(int ql,int qr,ll d){ rangeAdd(1,0,n,ql,qr,d); }
    void rangeAdd(int p,int l,int r,int ql,int qr,ll d){
        if(ql<=l && r<=qr){ apply(p,d); return; }
        push(p);
        int m=(l+r)>>1;
        if(ql<=m) rangeAdd(p<<1,l,m,ql,qr,d);
        if(qr>m)  rangeAdd(p<<1|1,m+1,r,ql,qr,d);
        pull(p);
    }

    Node query(int ql,int qr){ return query(1,0,n,ql,qr); }
    Node query(int p,int l,int r,int ql,int qr){
        if(ql<=l && r<=qr) return st[p];
        push(p);
        int m=(l+r)>>1;
        if(qr<=m) return query(p<<1,l,m,ql,qr);
        if(ql>m)  return query(p<<1|1,m+1,r,ql,qr);
        Node L = query(p<<1,l,m,ql,qr);
        Node R = query(p<<1|1,m+1,r,ql,qr);
        return mergeNode(L,R);
    }
};

/******** Tree for AB: bestAB = min_{i<j}(A[j]-B[i]) ********/
struct SegAB {
    struct Node { ll minA, maxB, best, lazyA, lazyB; };
    int n;
    vector<Node> st;
    SegAB() : n(0) {}
    SegAB(const vector<ll>& A, const vector<ll>& B){ init(A,B); }

    void init(const vector<ll>& A, const vector<ll>& B){
        n = (int)A.size()-1;
        st.assign(4*(n+1), {0,0,INF,0,0});
        build(1,0,n,A,B);
    }

    static Node mergeNode(const Node& L, const Node& R){
        Node res;
        res.minA = min(L.minA, R.minA);
        res.maxB = max(L.maxB, R.maxB);
        res.best = min({L.best, R.best, R.minA - L.maxB});
        res.lazyA = res.lazyB = 0;
        return res;
    }

    void apply(int p, ll dA, ll dB){
        st[p].minA += dA;
        st[p].maxB += dB;
        st[p].best += (dA - dB);
        st[p].lazyA += dA;
        st[p].lazyB += dB;
    }
    void push(int p){
        ll dA = st[p].lazyA, dB = st[p].lazyB;
        if(dA!=0 || dB!=0){
            apply(p<<1, dA, dB);
            apply(p<<1|1, dA, dB);
            st[p].lazyA = st[p].lazyB = 0;
        }
    }
    void pull(int p){ st[p] = mergeNode(st[p<<1], st[p<<1|1]); }

    void build(int p,int l,int r,const vector<ll>& A,const vector<ll>& B){
        st[p].lazyA = st[p].lazyB = 0;
        if(l==r){
            st[p].minA = A[l];
            st[p].maxB = B[l];
            st[p].best = INF;
            return;
        }
        int m=(l+r)>>1;
        build(p<<1,l,m,A,B);
        build(p<<1|1,m+1,r,A,B);
        pull(p);
    }

    void rangeAdd(int ql,int qr,ll dA,ll dB){ rangeAdd(1,0,n,ql,qr,dA,dB); }
    void rangeAdd(int p,int l,int r,int ql,int qr,ll dA,ll dB){
        if(ql<=l && r<=qr){ apply(p,dA,dB); return; }
        push(p);
        int m=(l+r)>>1;
        if(ql<=m) rangeAdd(p<<1,l,m,ql,qr,dA,dB);
        if(qr>m)  rangeAdd(p<<1|1,m+1,r,ql,qr,dA,dB);
        pull(p);
    }

    Node query(int ql,int qr){ return query(1,0,n,ql,qr); }
    Node query(int p,int l,int r,int ql,int qr){
        if(ql<=l && r<=qr) return st[p];
        push(p);
        int m=(l+r)>>1;
        if(qr<=m) return query(p<<1,l,m,ql,qr);
        if(ql>m)  return query(p<<1|1,m+1,r,ql,qr);
        Node L = query(p<<1,l,m,ql,qr);
        Node R = query(p<<1|1,m+1,r,ql,qr);
        return mergeNode(L,R);
    }
};

/******** Tree for BA: bestBA = min_{i<j}(B[j]-A[i]) ********/
struct SegBA {
    struct Node { ll minB, maxA, best, lazyB, lazyA; };
    int n;
    vector<Node> st;
    SegBA() : n(0) {}
    SegBA(const vector<ll>& A, const vector<ll>& B){ init(A,B); }

    void init(const vector<ll>& A, const vector<ll>& B){
        n = (int)A.size()-1;
        st.assign(4*(n+1), {0,0,INF,0,0});
        build(1,0,n,A,B);
    }

    static Node mergeNode(const Node& L, const Node& R){
        Node res;
        res.minB = min(L.minB, R.minB);
        res.maxA = max(L.maxA, R.maxA);
        res.best = min({L.best, R.best, R.minB - L.maxA});
        res.lazyB = res.lazyA = 0;
        return res;
    }

    void apply(int p, ll dB, ll dA){
        st[p].minB += dB;
        st[p].maxA += dA;
        st[p].best += (dB - dA);
        st[p].lazyB += dB;
        st[p].lazyA += dA;
    }
    void push(int p){
        ll dB=st[p].lazyB, dA=st[p].lazyA;
        if(dB!=0 || dA!=0){
            apply(p<<1, dB, dA);
            apply(p<<1|1, dB, dA);
            st[p].lazyB = st[p].lazyA = 0;
        }
    }
    void pull(int p){ st[p] = mergeNode(st[p<<1], st[p<<1|1]); }

    void build(int p,int l,int r,const vector<ll>& A,const vector<ll>& B){
        st[p].lazyB = st[p].lazyA = 0;
        if(l==r){
            st[p].minB = B[l];
            st[p].maxA = A[l];
            st[p].best = INF;
            return;
        }
        int m=(l+r)>>1;
        build(p<<1,l,m,A,B);
        build(p<<1|1,m+1,r,A,B);
        pull(p);
    }

    void rangeAdd(int ql,int qr,ll dB,ll dA){ rangeAdd(1,0,n,ql,qr,dB,dA); }
    void rangeAdd(int p,int l,int r,int ql,int qr,ll dB,ll dA){
        if(ql<=l && r<=qr){ apply(p,dB,dA); return; }
        push(p);
        int m=(l+r)>>1;
        if(ql<=m) rangeAdd(p<<1,l,m,ql,qr,dB,dA);
        if(qr>m)  rangeAdd(p<<1|1,m+1,r,ql,qr,dB,dA);
        pull(p);
    }

    Node query(int ql,int qr){ return query(1,0,n,ql,qr); }
    Node query(int p,int l,int r,int ql,int qr){
        if(ql<=l && r<=qr) return st[p];
        push(p);
        int m=(l+r)>>1;
        if(qr<=m) return query(p<<1,l,m,ql,qr);
        if(ql>m)  return query(p<<1|1,m+1,r,ql,qr);
        Node L = query(p<<1,l,m,ql,qr);
        Node R = query(p<<1|1,m+1,r,ql,qr);
        return mergeNode(L,R);
    }
};

static inline int isR(char c){ return c=='r'; }
static inline int isG(char c){ return c=='g'; }
static inline int isB(char c){ return c=='b'; }

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n,q;
    cin>>n>>q;
    string s; cin>>s;
    s = " " + s; // 1-indexed chars

    Fenwick fwR(n), fwG(n), fwB(n);
    for(int i=1;i<=n;i++){
        fwR.add(i, isR(s[i]));
        fwG.add(i, isG(s[i]));
        fwB.add(i, isB(s[i]));
    }

    // build prefix arrays at indices 0..n
    vector<ll> C(n+1), A(n+1), B(n+1);
    ll pr=0, pg=0, pb=0;
    C[0]=A[0]=B[0]=0;
    for(int i=1;i<=n;i++){
        pr += isR(s[i]);
        pg += isG(s[i]);
        pb += isB(s[i]);
        C[i] = pb - pg - pr;
        A[i] = pb - pg;
        B[i] = pb - pr;
    }

    SegC segC(C);
    SegAB segAB(A,B);
    SegBA segBA(A,B);

    while(q--){
        int tp; cin>>tp;
        if(tp==1){
            int x; char c; cin>>x>>c;
            char old = s[x];
            if(old==c) continue;

            int dr = isR(c) - isR(old);
            int dg = isG(c) - isG(old);
            int db = isB(c) - isB(old);

            // update BIT
            if(dr) fwR.add(x, dr);
            if(dg) fwG.add(x, dg);
            if(db) fwB.add(x, db);

            // update segment trees on prefix indices [x..n]
            ll dC  = (ll)db - (ll)dg - (ll)dr;
            ll dA  = (ll)db - (ll)dg;
            ll dBv = (ll)db - (ll)dr;

            if(x<=n){
                segC.rangeAdd(x, n, dC);
                segAB.rangeAdd(x, n, dA, dBv);
                segBA.rangeAdd(x, n, dBv, dA);
            }

            s[x]=c;
        }else{
            int l,r; cin>>l>>r;
            int L = l-1, R = r;

            auto nodeC  = segC.query(L,R);
            auto nodeAB = segAB.query(L,R);
            auto nodeBA = segBA.query(L,R);

            ll bestC  = nodeC.best;
            ll bestAB = nodeAB.best;
            ll bestBA = nodeBA.best;

            ll total_r = fwR.rangeSum(l,r);
            ll total_g = fwG.rangeSum(l,r);
            ll total_b = fwB.rangeSum(l,r);

            ll pref_g_r = fwG.sumPrefix(r);
            ll pref_r_lm1 = fwR.sumPrefix(l-1);
            ll pref_r_r = fwR.sumPrefix(r);
            ll pref_g_lm1 = fwG.sumPrefix(l-1);

            ll Sbound = total_r + total_g + bestC;
            ll Pbound = (pref_g_r - pref_r_lm1) + bestAB;
            ll Qbound = (pref_r_r - pref_g_lm1) + bestBA;

            Sbound = max(0LL, Sbound);
            Pbound = max(0LL, Pbound);
            Qbound = max(0LL, Qbound);

            ll ans = min(Sbound, Pbound + Qbound);
            ans = min(ans, min({total_b, total_r, total_g}));
            ans = max(0LL, ans);

            cout << ans << "\n";
        }
    }
    return 0;
}
```

## Subtask 1

考虑答案一定形如 `gbr`，取 $[l,r]$ 内 `r`、`g`、`b` 个数的最小值即为答案。

```cpp
namespace Subtask1{
	struct segTree{
		struct node{
			int l,r;
			int value;
		}t[N<<2|1];
		
		void up(int p){
			t[p].value=t[p<<1].value+t[p<<1|1].value;
		}
		void build(int p,int l,int r){
			t[p]={l,r};
			if(l==r){
				return;
			}
			int mid=l+r>>1;
			build(p<<1,l,mid);
			build(p<<1|1,mid+1,r);
			up(p);
```

## Subtask 2

$q,n\leq200$，显然是一个 $\mathcal O\left(qn^2\right)$ 左右的做法。

因此可以考虑每次把询问 $[l,r]$ 单独视为一个序列，然后求答案。

假设已知 `rbg` 个数为 $P$，`gbr` 个数为 $Q$。一种显然的贪心构造是左边的 `r` 尽可能分配给 `rbg`，左边的 `g` 尽可能分配给 `gbr`；右边就反过来。

因此，从左往右第 $i$ 个 `r` 属于 `rbg`，对应从右往左第 $P-i+1$ 个 `g`；从左往右第 $i$ 个 `g`，对应从右往左第 $Q-i+1$ 个 `r`。

因此枚举 $P,Q$ 后把 `r`、`g` 配对，变成一条条线段。$P,Q$ 合法的条件就是存在一种 `b` 的分配方式，使得每一条线段都覆盖了一个 `b`。

扫描线扫左端点，每次堆维护右端点的最小值，贪心分配 `b` 即可。

但是这样直接做的复杂度是 $\mathcal O\left(qn^3\right)$ 的。考虑 $P$ 增加的时候，$Q$ 不增。所以可以双指针，时间复杂度 $\mathcal O\left(qn^2\log n\right)$。

## Subtask 3

<details class="info" open>
    <summary>Hall 定理</summary>
    <p>
        Hall 定理指出，二分图 $G=(X,Y,E)$ 存在最大的匹配，使得 $X$ 中所有点都为匹配点，当且仅当对于 $\forall S\subseteq X$，$S$ 中的点能到达的点集的大小大于等于 $\vert S\vert$。
    </p>
</details>

仍然假设 $P,Q$ 已知。考虑匹配线段和 `b` 不好做，进行二分图建模。一条线段和 `b` 连边当且仅当 `b` 在原序列中的位置被线段覆盖。我们想知道的就是是否存在一个最大匹配，使得每条线段都是匹配点。

由 Hall 定理，这个条件等价于对于线段集的所有子集，能匹配到的 `b` 的数量都大于等于子集大小。

即 $P,Q$ 合法当且仅当 $\forall[p,q]\in[l,r]$，$[p,q]$ 中的线段数小于等于 $[p,q]$ 中 `b` 的数量。

记前缀 `r`、`g`、`b` 的数量分别为 $\textit{cntr}_i,\textit{cntg}_i,\textit{cntb}_i$，$[p,q]$ 中 `b` 的数量即 $\textit{cntb}_q-\textit{cntb}_{p-1}$。

先考虑 $[p,q]$ 中的 `rbg` 的数量。

Subtask 2 中提到过一种优先把左边的 `r` 分配给 `rbg` 的构造，这里还是一样。左端点 `r` 在 $[l,p)$ 中的 `rbg` 数量为 $\textit{cntr}_{p-1}-\textit{cntr}_{l-1}$，右端点 `g` 在 $(q,r]$ 中的 `rbg` 数量为 $\textit{cntg}_r-\textit{cntg}_q$。因为钦定的构造方式，不会重复统计。`gbr` 同理。可得：

$$
\max(P-(\textit{cntr}_{p-1}-\textit{cntr}_{l-1})-(\textit{cntg}_r-\textit{cntg}_q),0)+\\\max(Q-(\textit{cntg}_{p-1}-\textit{cntg}_{l-1})-(\textit{cntr}_r-\textit{cntr}_q),0)\leq\textit{cntb}_q-\textit{cntb}_{p-1}
$$

拆 $\max(\cdots,0)$，等价于对于 $\forall[p,q]\in[l,r]$，有：

$$
\begin{cases}
P-(\textit{cntr}_{p-1}-\textit{cntr}_{l-1})-(\textit{cntg}_r-\textit{cntg}_q)\ +\ Q-(\textit{cntg}_{p-1}-\textit{cntg}_{l-1})-(\textit{cntr}_r-\textit{cntr}_q)\leq\textit{cntb}_q-\textit{cntb}_{p-1}\\
P-(\textit{cntr}_{p-1}-\textit{cntr}_{l-1})-(\textit{cntg}_r-\textit{cntg}_q)\leq\textit{cntb}_q-\textit{cntb}_{p-1}\\
Q-(\textit{cntg}_{p-1}-\textit{cntg}_{l-1})-(\textit{cntr}_r-\textit{cntr}_q)\leq\textit{cntb}_q-\textit{cntb}_{p-1}
\end{cases}
$$

由此可以枚举 $p,q$，然后维护 $P+Q,P,Q$ 的最大值：

$$
\begin{cases}
P+Q\leq\textit{cntb}_q-\textit{cntb}_{p-1}+(\textit{cntr}_{p-1}-\textit{cntr}_{l-1})+(\textit{cntg}_r-\textit{cntg}_q)+(\textit{cntg}_{p-1}-\textit{cntg}_{l-1})+(\textit{cntr}_r-\textit{cntr}_q)\\
P\leq\textit{cntb}_q-\textit{cntb}_{p-1}+(\textit{cntr}_{p-1}-\textit{cntr}_{l-1})+(\textit{cntg}_r-\textit{cntg}_q)\\
Q\leq\textit{cntb}_q-\textit{cntb}_{p-1}+(\textit{cntg}_{p-1}-\textit{cntg}_{l-1})+(\textit{cntr}_r-\textit{cntr}_q)\\
\end{cases}
$$

直接枚举 $p,q$，仍然是 $\mathcal O\left(qn^2\right)$ 的，无法通过 Subtask 3。所以拆式子：

$$
\begin{cases}
P+Q\leq(\textit{cntr}_r-\textit{cntr}_{l-1}+\textit{cntg}_r-\textit{cntg}_{l-1})+(\textit{cntb}_q-\textit{cntg}_q-\textit{cntr}_q)-(\textit{cntb}_{p-1}-\textit{cntr}_{p-1}-\textit{cntg}_{p-1})\\
P\leq(\textit{cntg}_r-\textit{cntr}_{l-1})+(\textit{cntb}_q-\textit{cntg}_q)-(\textit{cntb}_{p-1}-\textit{cntr}_{p-1})\\
Q\leq(\textit{cntr}_r-\textit{cntg}_{l-1})+(\textit{cntb}_q-\textit{cntr}_q)-(\textit{cntb}_{p-1}-\textit{cntg}_{p-1})\\
\end{cases}
$$

这启发我们维护：

$$
\begin{aligned}
grb_i&=\textit{cntb}_i-\textit{cntg}_i-\textit{cntr}_i\\
\textit{gb}_i&=\textit{cntb}_i-\textit{cntg}_i\\
\textit{rb}_i&=\textit{cntb}_i-\textit{cntr}_i
\end{aligned}
$$

于是就转化为了：

$$
\begin{cases}
P+Q\leq(\textit{cntr}_r-\textit{cntr}_{l-1}+\textit{cntg}_r-\textit{cntg}_{l-1})+\textit{grb}_q-\textit{grb}_{p-1}\\
P\leq(\textit{cntg}_r-\textit{cntr}_{l-1})+\textit{gb}_q-\textit{rb}_{p-1}\\
Q\leq(\textit{cntr}_r-\textit{cntg}_{l-1})+\textit{rb}_q-\textit{gb}_{p-1}
\end{cases}
$$

枚举 $p-1$，再维护 $\textit{grb},\textit{rb},\textit{gb}$ 的后缀最值，即可 $\mathcal O(n)$ 回答询问。（考虑后缀最值维护 $q$ 的贡献，$p-1$ 的贡献直接算。）

时间复杂度 $\mathcal O(qn)$。

## Subtask 4

仍然考虑：

$$
\begin{aligned}
grb_i&=\textit{cntb}_i-\textit{cntg}_i-\textit{cntr}_i\\
\textit{gb}_i&=\textit{cntb}_i-\textit{cntg}_i\\
\textit{rb}_i&=\textit{cntb}_i-\textit{cntr}_i
\end{aligned}
\\
\begin{cases}
P+Q\leq(\textit{cntr}_r-\textit{cntr}_{l-1}+\textit{cntg}_r-\textit{cntg}_{l-1})+\textit{grb}_q-\textit{grb}_{p-1}\\
P\leq(\textit{cntg}_r-\textit{cntr}_{l-1})+\textit{gb}_q-\textit{rb}_{p-1}\\
Q\leq(\textit{cntr}_r-\textit{cntg}_{l-1})+\textit{rb}_q-\textit{gb}_{p-1}
\end{cases}
$$

每次询问都暴力重构肯定是不优的，因此思考修改 `r`、`g`、`b` 的取值，会对我们的信息造成什么影响。

显然 $\textit{cntr},\textit{cntg},\textit{cntb}$ 可以树状数组维护，对应地可以维护 $\textit{grb},\textit{gb},\textit{rb}$。

查询需要的就是求：

$$
\min_{i<j}(\textit{grb}_j-\textit{grb}_i)\\
\min_{i<j}(\textit{gb}_j-\textit{rb}_i)\\
\min_{i<j}(\textit{rb}_j-\textit{gb}_i)
$$

这是可以线段树维护的。考虑把数分成两类，维护区间最大值 $\textit{max}$、最小值 $\textit{min}$ 和区间最小差值 $\textit{diff}$，可以合并信息。

官方题解代码写了 $348$ 行，奇长无比，其实并没有必要。因为 $\textit{diff}$ 更新的时候一定是用右区间的 $\textit{min}$ 减左区间的 $\textit{max}$。所以可以复用代码。

把 $\textit{min},\textit{max}$ 的加法标记分开维护，分开加即可。

# 题目描述

## 题目背景

YYX 转职成了搏斗教练！

## 题目描述

YYX 手下有 $n$ 个学员，编号依次为 $1,2,\dots,n$，编号为 $i$ 的学员能力值为 $a_i$。YYX 希望选出一些学员进行对抗训练，具体的，她会选定一个 $m$ 和队伍长度 $l$，使得 $l \le m \le n - l$，让编号在 $[m-l+1, m]$ 的学员为一队，编号在 $[m+1, m+l]$ 的学员为另一队。

YYX 希望选出的两队势均力敌，YYX 认为一个队最重要的是能力值最高的学员，因此，她希望两队能力值最高的学员的能力值之差不超过 $K$。具体的：

$$
\left|\max_{m-l+1 \le i \le m}\{a_i\} - \max_{m+1 \le i \le m+l}\{a_i\}\right| \le K
$$

YYX 想要知道哪些 $(m, l)$ 对可以构成势均力敌的两队。但是她太笨了，所以她找到了你，希望你帮她解决问题。

由于可能的 $(m, l)$ 对数可能很多，对每个 $l$，记和 $l$ 能组成合法的 $(m, l)$ 对的所有 $m$ 构成的集合为 $S_l$，你只需要求出：

$$
ans_l = \sum_{m \in S_l} a_m^2
$$

即可。

## 输入格式

本题采用多组测试。

第一行一个整数 $T$ 表示数据组数。

对于每组数据，第一行两个整数 $n, K$ 表示学员个数和能力值最大差值。  
第二行 $n$ 个整数表示 $\{a_i\}$。

## 输出格式

对于每组数据，输出一行 $n$ 个整数，第 $i$ 个整数表示 $ans_i$。

## 样例解释

对于第一组样例：

- 对于第一组数据，可能的 $(m,l)$ 对有 $(2,2),(3,2),(4,2),(3,3)$，故 $ans_2 = \sum_{m=2}^4 a_m^2 = 11$，$ans_3 = a_3^2 = 9$。

- 对于第二、三组数据，注意到 $\{a_i\}$ 极差都不超过 $K$，故 $ans_l = \sum_{m=l}^{n-l} a_m^2$。

## 数据范围

对于全部的数据，  
$1 \le n \le 5 \times 10^5$，$0 \le K \le 10$，$1 \le a_i \le n$。所有数据的 $n$ 之和不超过 $5 \times 10^5$。

# 官方题解

给定长度为 $n$ 的数组 $a_i$ 和常数 $K$，对于每个 $1 \le l \le n$，求出有哪些 $m$ 满足：

$$
\left|\max_{m-l+1 \le i \le m}\{a_i\} - \max_{m+1 \le i \le m+l}\{a_i\}\right| \le K
$$

记这些 $m$ 构成的集合为 $S_l$，求：

$$
ans_l = \sum_{m \in S_l} a_m^2
$$

多组测试，$\sum n \le 5 \times 10^5$，$0 \le K \le 10$。

## Subtask 1

枚举 $m$ 后枚举 $l$ 依次判定即可，复杂度 $O(n^2)$。

## Subtask 2

该档部分分是给一些根号做法或者写挂的正解的，如果你的暴力效率足够高也能通过。

## Subtask 3

此时值互不相同，令：

$$
L = \max_{m-l < i \le m}\{a_i\},\quad R = \max_{m < i \le m+l}\{a_i\}
$$

满足 $|R - L| \le K$ 的二元组 $(L,R)$ 至多 $O(nK)$ 个。

但如果只枚举 $L,R$，我们仍然难以求出对应的合法 $(m,l)$ 的分布。于是额外枚举 $m$，那么此时合法的 $l$ 要么是空集要么一定是一个区间。假如我们可以把所有至少存在一个合法 $l$ 的三元组 $(L,R,m)$ 求出，那么可以使用单调栈在线性于三元组数量的时间，对于每个三元组把对应的 $l$ 的范围求出。

我们断言这样的三元组数量不超过 $O(nK\log n)$，接下来说明如何找到所有 $(L,R,m)$ 对并证明数量上界：

不妨 $L < R$ 然后再反过来再做一次。

枚举 $L = a_i$，令 $p_0 = i$，找到 $a_{p_i}$ 为 $a_{p_{i-1}}$ 右边第一个比它大的。那么找到：

$$
a_i < a_{p_1} < a_{p_2} < \dots < a_{p_o} \le a_i + K
$$

并令 $a_l$ 为 $a_i$ 左边第一个比它大的。

当 $R = a_{p_j}$ 时，我们取的 $m$ 需要满足：

- $i \le m < p_1$
- $m \ge \dfrac{l + p_j}{2}$，否则当子段覆盖 $a_{p_j}$ 时也会覆盖 $a_l$。
- $m \le \dfrac{p_{j+1} + i}{2} - 1$，否则当子段覆盖 $a_i$ 时也会覆盖 $a_{p_{j+1}}$。（如果这样的 $p_{j+1}$ 不存在则设为 $n+1$）

只需要满足这些条件的 $m$ 都是可行的。那么这样的 $m$ 个数为：

$$
O\left(\min\left(p_1 - i,\ \frac{1}{2}(p_{j+1} - p_j + i - l)\right)\right)
$$

考虑建大根笛卡尔树，那么 $p_1 - i$ 为 $i$ 的右子树大小，$i - l$ 为 $i$ 的左子树大小，$p_{j+1} - p_j$ 为 $p_j$ 的右子树大小，且 $p_j$ 是 $i$ 的祖先。

把三者依次设为 $A,B,C$，那么：

$$
\min\left(A,\frac{1}{2}(B+C)\right) \le \min(A,B) + \min(A,C)
$$

前者为 $i$ 两个子树大小较小值，后者不大于 $p_j$ 两个子树大小较小值。

考虑每个点至多被作为 $L$ 和 $R$ 各 $K$ 次，故可能的三元组总数上界即为 $O(K)$ 乘上笛卡尔树每个点两个子树大小较小值之和，即为 $O(n\log n)$。

那么总复杂度即为 $O(nK\log n)$。

## Subtask 4

当序列不再是排列时上述结论依旧成立，证明可以扩展上述证明，考虑在笛卡尔树上把值相同的部分缩在一起讨论。

但此时你需要精细实现，保证找三元组的复杂度即为 $O(\text{三元组个数})$，并且找的三元组不重不漏。总复杂度 $O(nK\log n)$。

> 事实上出题人并没有想到使三元组数量为 $\Omega(nK)$ 的构造方法，如果你有想法欢迎联系出题人。

```cpp
#include <bits/stdc++.h>
typedef long long ll;
using namespace std;
int n,m,a[500010],pre[2][500010],suf[2][500010];
ll ans[500010];

void add(ll k,int l,int r){
  assert(l<=r+1);
  ans[l]+=k;
  ans[r+1]-=k;
}
void sol(){
  scanf("%d%d",&n,&m);
  for(int i=1;i<=n;i++) scanf("%d",&a[i]),ans[i]=0;
  a[0]=a[n+1]=n+m+1;
  for(int j=0;j<2;j++){
    for(int i=1;i<=n;i++){
      pre[j][i]=i-1;
      while(a[pre[j][i]]<a[i]+j) pre[j][i]=pre[j][pre[j][i]];
    }
    for(int i=n;i>=1;i--){
      suf[j][i]=i+1;
      while(a[suf[j][i]]<a[i]+j) suf[j][i]=suf[j][suf[j][i]];
    }
  }
  // 在实际实现中，我们并不需要真的枚举 p_i 逐个算，而是可以合并起来。
  for(int i=1;i<=n;i++){
    int j=suf[0][i],l=pre[1][i],r=j;
    while(a[r]<=a[i]+m) r=suf[1][r];
    int qL=max(i,(l+j+1)/2);
    int qR=min(j-1,(r+i)/2-1);
    for(int k=qL;k<=qR;k++){
      add(1ll*a[k]*a[k],max(k-i+1,j-k),min(k-l,r-k-1));
    }
  }
  // 上面处理了 L=R 的情况，下面需要保证 L > R。
  for(int i=1;i<=n;i++){
    int j=pre[1][i],r=suf[1][i],p=pre[0][i],l=j;
    while(a[l]<=a[i]+m) l=pre[1][l];
    int qL=max(p,(l+i+1)/2);
    int qR=min(i-1,(r+j)/2-1);
    for(int k=qL;k<=qR;k++){
      add(1ll*a[k]*a[k],max(k-j+1,i-k),min(k-l,r-k-1));
    }
  }
  for(int i=2;i<=n;i++) ans[i]+=ans[i-1];
  for(int i=1;i<=n;i++) printf("%lld ",ans[i]);
  puts("");
}
int main(){
  int T;
  scanf("%d",&T);
  while(T--) sol();
  return 0;
}
```

之后观察数据范围发现 $k\leq10$，应该有一些性质。

Subtask1 和 Subtask2 已经被暴力过掉了，考虑 Subtask3，$a_1,a_2,\cdots,a_n$ 是一个 $1\sim n$ 的排列。

考虑这个东西和排列本身的性质没有什么关系，得到了关于 $a$ 的另一个性质——$a_1,a_2,\cdots,a_n$ 互不相同。

记：

$$
L=\max_{i=m-l+1}^ma_i,R=\max_{i=m+1}^{m+l}a_i
$$

则有满足 $\vert L-R\vert\leq k$ 的二元组 $(L,R)$ 至多 $\mathcal O(nk)$ 个。

然而，只有 $L,R$ 无法得到 $(m,l)$ 和答案。所以枚举 $(L,R,m)$。

~~根据官方题解，~~这样的三元组个数为 $\mathcal O(nk\log n)$。

所以找到三元组后，区间增加 $\textit{ans}$ 即可。

发现有相同的时候，只需要精细时间即可。

```cpp
//#include<bits/stdc++.h>
#include<algorithm>
#include<iostream>
#include<cstring>
#include<iomanip>
#include<cstdio>
#include<string>
#include<vector>
#include<cmath>
#include<ctime>
#include<deque>
#include<queue>
#include<stack>
#include<list>
using namespace std;
typedef long long ll;
constexpr const int N=5e5,K=10,inf=0x3f3f3f3f;
int n,m,a[N+1],pre[2][N+1],suf[2][N+1];
ll ans[N+1+1];
int main(){
	freopen("battle.in","r",stdin);
	freopen("battle.out","w",stdout);
	
	ios::sync_with_stdio(false);
	cin.tie(0);cout.tie(0);
	
	int T;
	cin>>T;
	while(T--){
		cin>>n>>m;
		for(int i=1;i<=n;i++){
			cin>>a[i];
			ans[i]=0;
		}
		a[0]=a[n+1]=inf;
		for(int i=0;i<2;i++){
			for(int x=1;x<=n;x++){
				pre[i][x]=x-1;
				while(a[pre[i][x]]<a[x]+i){
					pre[i][x]=pre[i][pre[i][x]];
				}
			}
			for(int x=n;1<=x;x--){
				suf[i][x]=x+1;
				while(a[suf[i][x]]<a[x]+i){
					suf[i][x]=suf[i][suf[i][x]];
				}
			}
		}
		for(int i=1;i<=n;i++){
			int l=pre[1][i],r=suf[0][i];
			while(a[r]<=a[i]+m){
				r=suf[1][r];
			}
			int L=max(i,(l+suf[0][i]+1)/2);
			int R=min(suf[0][i]-1,(r+i)/2-1);
			for(int k=L;k<=R;k++){
				ans[max(k-i+1,suf[0][i]-k)]+=1ll*a[k]*a[k];
				ans[min(k-l,r-k-1)+1]-=1ll*a[k]*a[k];
			}
		}
		for(int i=1;i<=n;i++){
			int r=suf[1][i],l=pre[1][i];
			while(a[l]<=a[i]+m){
				l=pre[1][l];
			}
			int L=max(pre[0][i],(l+i+1)/2);
			int R=min(i-1,(r+pre[1][i])/2-1);
			for(int k=L;k<=R;k++){
				ans[max(k-pre[1][i]+1,i-k)]+=1ll*a[k]*a[k];
				ans[min(k-l,r-k-1)+1]-=1ll*a[k]*a[k];
			}
		}
		for(int i=1;i<=n;i++){
			ans[i]+=ans[i-1];
			cout<<ans[i]<<' ';
		}
		cout<<'\n';
	}
	
	cout.flush();
	
	/*fclose(stdin);
	fclose(stdout);*/
	return 0;
}
```
